# Jing-R# Data and Code for Jing River Basin Water Footprint and Scarcity Assessment

This repository provides the processed non-confidential datasets, Copula analysis scripts, sub-basin shapefiles, model input data, and model output files used in the study.

Raw streamflow and water quality monitoring data are not publicly available due to data-use restrictions and national data security regulations.

## Contents


- `ET/`: Evapotranspiration datasets used for water balance analysis and model evaluation. These data were processed to match the spatial extent of the Jing River Basin.

- `Landuse/`: Land use data used for hydrological response unit (HRU) definition and land use classification in the SWAT model.

- `Soil/`: Soil datasets used to define soil physical and hydraulic properties required by the SWAT model.

- `Model output/`: Processed model output files, including water footprint, water scarcity, pollutant load, and related sub-basin-scale results used for subsequent statistical and Copula analyses.

- `copulas/`: R scripts for marginal distribution fitting, Copula model selection, and joint risk analysis.

- `shp/`: Sub-basin boundary files used for spatial analysis and mapping.

## Data availability

Publicly shareable datasets, processed results, and analysis codes are provided in this repository. Raw streamflow and water quality monitoring data are not publicly available because they are subject to data-use restrictions and national data security regulations.
